TRAFFIC LIGHT CONTROLLER USING FSM
FINAL PROJECT RESULTS REPORT
=============================

1. PROJECT OVERVIEW
-------------------

Project Title:
Traffic Light Controller using FSM

Design Type:
Moore Finite State Machine

Purpose:
Control traffic signals for two intersecting roads using a
clock-driven finite state machine and configurable timers.

Traffic Directions:
North/South (NS)
East/West (EW)


2. DESIGN ARCHITECTURE
----------------------

The design consists of three RTL modules:

1. traffic_fsm.v
   Implements the six-state finite state machine and generates
   Moore-model traffic-light outputs.

2. traffic_timer.v
   Implements the configurable state-duration timer.

3. traffic_light_controller.v
   Integrates the FSM and timer into the complete controller.


3. FSM ARCHITECTURE
-------------------

Number of FSM states:
6

State sequence:

NS GREEN
   ↓
NS YELLOW
   ↓
ALL RED 1
   ↓
EW GREEN
   ↓
EW YELLOW
   ↓
ALL RED 2
   ↓
NS GREEN

State encoding:

NS GREEN  = 000
NS YELLOW = 001
ALL RED 1 = 010
EW GREEN  = 011
EW YELLOW = 100
ALL RED 2 = 101


4. CLOCK AND TIMING
-------------------

Clock period:
10 ns

Clock frequency:
100 MHz

State durations:

NS GREEN   = 10 cycles = 100 ns
NS YELLOW  =  3 cycles =  30 ns
ALL RED 1  =  2 cycles =  20 ns
EW GREEN   = 10 cycles = 100 ns
EW YELLOW  =  3 cycles =  30 ns
ALL RED 2  =  2 cycles =  20 ns

Complete FSM cycle:
300 ns

7. SAFETY VERIFICATION
----------------------

The controller prevents simultaneous green signals for the
two traffic directions.

When NS GREEN is active:
EW GREEN remains inactive.

When EW GREEN is active:
NS GREEN remains inactive.

The controller also includes two ALL-RED states between the
direction changes.

These states provide an intermediate red interval before
traffic flow is transferred to the opposite direction.
