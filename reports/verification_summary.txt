2. VERIFICATION OBJECTIVES
--------------------------

The verification environment checks:

1. Correct reset behavior.
2. Correct FSM state transitions.
3. Correct traffic-light outputs for every FSM state.
4. Correct timer operation.
5. Correct timing sequence.
6. Mutual exclusion of NS and EW green signals.
7. Absence of simultaneous green signals.
8. Absence of simultaneous green and yellow signals
   for the same direction.
9. Absence of unknown or high-impedance traffic-light outputs.
10. Correct return to NS GREEN after a complete FSM cycle.
11. Correct operation after reset during an active EW GREEN state.
12. Repeated operation over multiple complete FSM cycles.


3. FSM STATES VERIFIED
----------------------

State 0 : NS GREEN
State 1 : NS YELLOW
State 2 : ALL RED 1
State 3 : EW GREEN
State 4 : EW YELLOW
State 5 : ALL RED 2

Expected sequence:

NS GREEN → NS YELLOW → ALL RED 1
→ EW GREEN → EW YELLOW → ALL RED 2
→ NS GREEN


4. OUTPUT SAFETY VERIFICATION
-----------------------------

NS GREEN and EW GREEN are mutually exclusive.

During NS GREEN:
NS GREEN = 1
EW GREEN = 0

During EW GREEN:
EW GREEN = 1
NS GREEN = 0

During ALL-RED states:
NS RED = 1
EW RED = 1

The verification testbench also checks that a direction does
not have GREEN and YELLOW active simultaneously.


5. TIMING VERIFICATION
-----------------------

Clock period: 10 ns

NS GREEN   : 10 cycles = 100 ns
NS YELLOW  :  3 cycles =  30 ns
ALL RED 1  :  2 cycles =  20 ns
EW GREEN   : 10 cycles = 100 ns

ALL RED 2  :  2 cycles =  20 ns
